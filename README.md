# Chatsy

**Zero-trace, end-to-end encrypted group chat.**

Chatsy is a modern real-time chat web application designed around one core promise:  
**no conversation data is ever stored on the server or in any database.**

Messages exist only:
- In the server’s RAM while a room is active (pure relay)
- Never (not even in the browser)

Late joiners cannot see previous messages. Rooms disappear when the last person leaves.  
Nothing can be recovered — not even by the operators.

---

## Features

- End-to-end encryption (AES-256-GCM via Web Crypto API)
- 6-digit invite codes generated by the server
- Three beautiful UI modes:
  - **Glassmorphism** (green + cyan + deep blue)
  - **Neomorphism** (soft white + green)
  - **Night** (black + red/pink glass)
- Modern bento-grid lobby
- Fully responsive (mobile → desktop)
- Smooth Framer Motion animations & interactive transitions
- Animated modern icons (Lucide + motion)
- Custom cursor behavior (pointer on interactive elements)
- Typing indicators & online user list
- No local history either

## Quick Start

```bash
# 1. Install dependencies
cd server && npm install
cd ../client && npm install

# 2. Run development servers
# Terminal 1
cd server && npm run dev          # → http://localhost:3001

# Terminal 2
cd client && npm run dev          # → http://localhost:5173
```

Open http://localhost:5173 in two browser windows (or one normal + one incognito) to test multi-user chat.

### Production

```bash
cd client && npm run build
cd ../server && npm start
# Serves the built frontend + Socket.io on PORT (default 3001)
```

## How Encryption Works

1. A 6-digit room code is generated when a room is created.
2. Every client derives the same AES-256 key from that code using PBKDF2 (100 000 iterations).
3. Messages are encrypted **in the browser** before being sent.
4. The server only ever receives and broadcasts ciphertext + IV.
5. Recipients decrypt with the same derived key.

The server cannot read messages. There is no key escrow.

## Privacy Model

| Data                     | Stored on Server? | Stored in Browser?      | Recoverable? |
|--------------------------|-------------------|-------------------------|--------------|
| Message content          | Never             | Optional (localStorage) | No (server)  |
| Room history             | Never             | Optional                | No           |
| User list (active)       | RAM only          | No                      | No           |
| Room after last leave    | Destroyed         | —                       | No           |
